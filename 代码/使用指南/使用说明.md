## 🔥 <span id="前言">前言</span>

商城销售毕业论文、普刊、编译三类课程与虚拟服务。买方使用用户Web、移动客户端、桌面端或微信小程序；站方使用响应式后台管理商品与交付。正式品牌和经营价格由运营方配置，种子商品及支付供开发演示。

## 一、<span id="start">启动与登录</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

按[部署说明](../../部署/README.md)运行对应系统入口，用户端访问启动日志中的`/client/`地址，管理端访问`/admin/`地址。客户账户为customer，管理员为admin，密码使用本机部署时配置的值。桌面入口与平台说明见[桌面端](../前端/PC端/Python/README.md)，微信独立工程见[小程序](../前端/微信小程序/README.md)。关闭运行终端，服务将结束。

## 二、<span id="buy">浏览与购买</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 在首页选毕业论文、普刊或编译，进入商品列表并查看详情，核对服务内容、价格及交付说明。
- 点击立即购买，登录后创建待付款订单。下架、缺货及版本过期商品不可新购。
- 在订单打开收银台，选择支付宝或微信，点击确认模拟付款，订单进入待完成。取消弹窗不会付款，模拟付款不会扣款。
- 价格、名称及服务条款以订单快照保留，后续后台商品编辑不改变已下单内容。

## 三、<span id="operations">站方管理与交付</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 管理员登录后台，在商品中新增或编辑类别、课程／服务、名称、简介、详情、价格、图片和详情分节，保存后可调整上下架和缺货。
- 已付款订单显示站方待交付状态，点击开始服务，再填写实际交付内容并提交。当前交付说明为文字；课程资源和具体服务成果由经营方按商品约定提供。
- 买方在待完成订单查看交付说明并确认完成，订单进入待评价；填写评分和评价后成为已完成。未付款订单可以取消。

## 四、<span id="display">语言、主题与离线</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

设置入口提供白天、黑夜、跟随系统和十语言；语言至少含简体中文、繁体中文、藏文、英文、日文、法文、西班牙文、德文、俄罗斯文、韩文。商品内容按后台输入原文显示。

进入页面、刷新和写操作优先请求API，服务不可用时回退隔离演示，后续请求成功自动显示服务端数据。每个商品和订单列表可重新加载，空列表有完整空态；商品图片加载失败保留本地品牌图。真实写结果未知时保留原请求键进行核对或重试，演示操作不补发成正式订单。
