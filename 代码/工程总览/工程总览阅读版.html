🔥 前言

“知序”是暂定品牌，为客户和运营人员提供毕业论文、普刊、编译三项服务的统一工作流。维护者Jobs，当前状态为在研MVP / 可运行联调版。已落地前后端和主要闭环；当前固定客户/管理员账户，不等于完整生产运营系统。普通操作者先双击开始使用，或阅读零基础使用说明。

当前规范入口为项目需求与开发评审（离线阅读版）、测试与分级验收、交付与运维清单。沿用已确认的 Python／Flutter／Go 路线，保留原 V0.3 资料与既有验证记录；补填字段、Q 项及正式验收范围在主评审收口。历史测试数字保留原日期，不代表当前源码已重新通过全端验收。

代码、测试、需求三个资料主目录的一级仅保留 README.md 与子目录；文档原稿、同主题阅读版及附件按职责或标题集中，入口由本页导航。

二、运行、构建与测试 🔼 🔽

零基础完整流程见使用说明。同时复制根目录并列的 代码/ 与 部署/ 到服务器，运行 部署/ 内对应平台入口；管理员页面和用户Web已随目录带入，服务器不必装Flutter或Node。

开发者在 后端/后端代码 运行：

go run ./cmd/server
python3 ../../../测试/运行测试.py/运行测试.py --group go
go vet ./...

移动用户端在 前端/移动端/Flutter，后台入口在 前端/后台管理端/Flutter；两者各自使用 lib/main.dart。后台通过本地路径依赖共用移动端工程的 zhixu 包，不复制业务、仓库或主题。Web 构建分别在对应工程执行；桌面 APP／DMG 在 前端/PC端/Python/dist，Windows EXE 须在 Windows 本机生成。

工程根的整合保护：

python3 ../测试/运行测试.py/运行测试.py \
  --group http \
  --group deploy \
  --group mini

所有测试使用独立夹具和临时数据。正式数据、真实收付款与对外消息不作为测试输入。回归报告列出各轮结果与未验收项。

2.1、本地部署＋内网穿透 🔼 🔽

关闭此运行终端，服务将结束。本地临时模式在确认公开前及地址生成后的日志中单独提示；终端支持颜色时为红色加粗，纯文本终端及日志保留原文。当前窗口管理本次后端和隧道，关闭终端或按 Ctrl+C 结束本次临时服务，数据与配置保留。

前期少量访问可将根目录并列的 代码/ 与 部署/ 留在现有电脑上运行，无需先采购云主机。运行 部署 内本系统入口，阅读说明并按回车后，通过 fzf 选择“本地部署＋内网穿透”或“服务器部署”；方向键选择、回车确认，Esc 取消。脚本复用健康工具，只在缺失时准备当前模式所需依赖。

1、从部署入口总览选择当前系统的“快捷入口”并双击；命令行也可运行包内规范脚本。本地模式完成账户预检后，构建并启动 127.0.0.1:8080，通过健康检查后启动免费 Cloudflare Quick Tunnel，输出本次随机 HTTPS 地址。DATABASE_URL 留空使用文件模式，不必先安装 PostgreSQL；首次需设置两个不同的非默认强密码。

2、本项目的网页、API 和文件统一穿透到 127.0.0.1:8080；与李林哲项目同机时，另用一个域名和隧道指向其 127.0.0.1:8098，各自保留数据目录。保持公网 Host 与浏览器 Origin 匹配，不默认重写为 localhost。固定地址可选 cpolar 或命名隧道；cpolar 两条隧道由同一客户端进程运行。

3、本地模式保持终端运行，按 Ctrl+C 退出时回收本次启动的隧道与服务，保留数据和账户配置。“服务器部署”沿用服务器启动流程，不启动公网隧道。手机关闭 Wi-Fi，验证登录、真实提交后刷新重读、上传和私有文件授权下载；本地演示回退不算服务器成功。睡眠、断网或重启会影响外部访问。

平台安装、可复制命令、固定域名、停止与排查见详细部署教程，离线浏览见部署阅读版。当前公网穿透及最低资源档仍未完成实机验收。
