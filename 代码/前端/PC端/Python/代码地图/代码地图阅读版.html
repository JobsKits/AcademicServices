🔥 前言

本图只定位 Python 桌面独立工程；工程在本单元的 Zhixu/，Python 包身份仍为 src/zhixu。Windows／MacOS 使用同一份业务源码，分别在目标系统构建。路径均从当前文档相对指向源码；跨单元内容只通过链接引用。

当前商城唯一入口：../Zhixu/src/zhixu/app.py的main创建ShopWindow；shop.py负责商品分类、详情、收银台、订单及设置；shop_repository.py负责API、隔离演示、订单动作及幂等键；Assets/shop_strings.json负责十语言；settings.py持久化主题、语言及连接选项。页面使用本地Assets/brand.svg兜底，远程图异步加载。

一、入口与模块职责 🔼 🔽

本单元路径 职责
Zhixu/src/entry.py 冻结程序的入口。
Zhixu/src/zhixu/app.py Python 图形界面、主窗口、服务表单、动作与主题呈现。
Zhixu/src/zhixu/repository.py 同一后端的 HTTP 请求与演示／未知结果保护。
Zhixu/src/zhixu/settings.py 连接及主题偏好、用户数据位置。
Zhixu/Scripts/manage.py 环境准备、本机打包、产物安全检查及冻结包首屏验证。
Zhixu/Scripts/bootstrap.ps1 Windows 环境准备与运行／打包入口的承接。
Zhixu/pyproject.toml 包身份、依赖声明、命令入口与资源清单。

flowchart LR
