## 🔥 <span id="前言">前言</span>

使用 [**C#**](https://learn.microsoft.com/dotnet/csharp/) 与 [**Windows Forms**](https://learn.microsoft.com/dotnet/desktop/winforms/) 原生控件，交付自含运行时的Windows x64 EXE，不需要Python／Qt／浏览器运行时。

## 一、<span id="run">运行与构建</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

运行 `Dist/win-x64/Zhixu.exe`，分发时保留整个 `win-x64/`，包括应用、运行时和 `Assets/`。`SourceManifest.sha256`／`ResourceManifest.sha256`分别记录相对源码及资源摘要。支持的Windows版本按.NET 11 Windows桌面运行时要求核对，目标机器实际运行另验。

当前包已在Mac完成交叉发布，EXE核对为PE32+ GUI x86-64；11项源码／工程记录及21项随包资源摘要均已核对，`Assets/`与工程引用的Web素材源目录逐字节相同。Windows真实启动、鼠标、GIF、字体及系统主题尚未验收。

本机需要 [**.NET SDK**](https://dotnet.microsoft.com/download) 11。打开PowerShell运行 `./构建.ps1`，阅读自述后回车；非交互使用 `./构建.ps1 -Build`。首次NuGet还原会下载官方Windows引用包和运行时，不安装系统级软件；脚本从自身位置定位源码与输出，失败不报成品成功。

```powershell
./构建.ps1 -Build
```

工程文件 `Zhixu.Windows.csproj` 可在Visual Studio打开。`dotnet publish -c Release -r win-x64 --self-contained true` 也可从其它宿主交叉构建；交叉发布不等于Windows实机验收。

## 二、<span id="source">源码、设置与生命周期</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

`Program.cs`负责原生窗口、商品／详情、订单、账户、资料、文件选择与设置；`NativeHeaderControls.cs`提供同一基线的主副标题与两项账户菜单；`NativeCategoryPager.cs`提供分类卡片与内容分页、左右键和横向拖动联动；`NativeOrderPager.cs`提供六种订单状态的计数卡片、可横滚卡片栏及联动内容；`NativeProductCard.cs`提供整张商品卡的鼠标／键盘详情导航与拖动取消点击；`NativeAvatarDialog.cs`提供八个本地预埋头像、PNG／JPEG／GIF本地选择与保留多帧的GIF显示；`NativeAuthDialog.cs`提供三张独立认证卡片，`NativePasswordInput.cs`使用单一原生TextBox与GDI+眼睛切换明文／密文，`LocalDemoAuth.cs`实现不落盘的演示验证码与盐哈希临时账户；`ShopStore.cs`负责HTTP、状态、演示隔离、未知写幂等和环境／身份迟到响应门禁；`.csproj`显式打包相邻Web的素材与许可字体。没有WebView或跨平台GUI控件层。

首页将“把成长，放在心上。”及副标题放入顶栏导航后的留白，二者在同一行、以一个空格相接；窄窗口或长翻译使用单行截断，完整文案保留给辅助功能。窗口默认1140×820、最小960×600，改变宽度时重新计算内容及轮播尺寸。轮播容器宽度随窗口调整，高度为原布局的一半：`clamp(round(宽度×0.405), 240, 390)÷2`，即120—195逻辑像素；图片使用Zoom等比完整显示，不拉伸或裁掉标题。分类卡片每张均为同一水平行的图标、标题和数量，数量18pt、标题12pt；卡片与下方内容采用同一选择状态，支持点击、左右键与横向拖动，减少动态效果时直接切页。订单不再重复显示大标题，无数据模块在筛选栏以下的当前数据区域居中，保留重新加载。

商品卡的图片、标题、介绍、价格与卡内空白均可进入同一详情，也可聚焦卡片后按Enter／空格；详情入口只导航，不直接购买。横向拖动分类内容时取消该次点击，避免滑动后误进详情；原“查看详情”按钮保持独立键盘动作。详情的返回按钮同时显示本地绘制左箭头与本地化文字，返回时恢复原分类选择。

订单状态采用六张水平卡片：全部、待付款、待完成、待评价、已完成、已取消，分别显示当前账户当前订单集的实际数量，包含总数和0；数量18pt、标题12pt，不沿用普通筛选按钮。卡片栏在最小960宽度下可横向滚动，切换后自动露出选中卡片。点击卡片、左右键／PageUp／PageDown和内容区横向拖动共用同一筛选状态，减少动态效果时直接换页；切换不触发支付、取消或确认动作，订单操作仍由其专属按钮进入。文本框保留正常文本选择，不抢占左右键。没有订单时，占位图文和重新加载入口在卡片栏以下的数据区域居中，随窗口宽高重新定位。

个人中心点击头像或“选择头像”进入预埋／本地选图；GIF以原始帧和流保留显示，不转成首帧位图，不沿用旧的2MiB客户端限制，服务端大小及图像校验错误在选择面板内显示。头像下提供心情与编辑入口，未填写时显示默认句。个人资料显示不可编辑的系统UID，用户名、邮箱、手机号分别编辑；邮箱／手机号不做格式或验证码校验，原样发送及显示。资料及头像先请求API，离线演示仅修改当前内存身份，退出后不保留、不上传；在线资料由服务端保存。个人中心订单入口与顶部“我的订单”使用同一导航；仅演示环境显示“演示版”。

右上角用户名打开只有“切换账号”和“退出”的原生下拉菜单，退出始终红底白字；个人中心不再重复放退出登录按钮。切换账号先撤销当前会话并回到正常认证门，仍可选择本地演示角色或输入普通账号，不能跳过认证或直接冒充另一身份；取消切换时保持退出状态。

设置采用左对齐标题、分组和字段，白天／黑夜／跟随系统与十语言始终可用；只有Demo显示服务地址与请求超时。设置保存后关闭，取消不写偏好。

默认API `http://127.0.0.1:8080/api/v1`，2500ms，可配置500—10000ms。进入／刷新／写操作先请求接口。只有精确回环地址且shop-config明确Demo，或本地网络确实不可达且从未明确正式环境，才提供上方买方身份选择及预填的 `customer / demo-customer`；Demo默认明文，原生图形眼睛可切密文。远程正式不提供Demo入口／预填／失败自动演示，401／403／409／422不回退为成功。真实写结果未知保留原幂等键，由原业务表单以相同内容重试，不在页脚常驻“重试原请求”；演示数据不补传。主题／语言／地址／超时写入当前用户LocalApplicationData下 `Jobs/ZhixuNative/preferences.json`，口令／Token／演示订单仅内存。关闭窗口退出，不创建后台服务。

未登录点击“我的订单／我的”直接打开登录，登录成功进入原目标，取消不跳转；认证空态只提供登录提示，真实登录后的数据空态仍可重新加载。页脚仅保留来源状态及设置，移除常驻重载／重试。登录、注册、忘记密码是三张独立卡片，采用同一固定660逻辑像素高窗口，左轨三个入口等分填满，右卡不再重复大标题，文本及密码输入框42逻辑像素高，长表单内部滚动。左轨大入口和文本链接可切换，保留active态、Tab／Enter键盘、700ms位置过渡及Windows减少动态效果。注册／重置动作分别为创建账号／重置密码，成功回登录。密码和确认密码均有可访问的原生图形眼睛；本地演示临时账号与验证码只驻内存，密码盐哈希，不写入偏好文件。

支持白天／黑夜／系统和简繁藏英日法西德俄韩；商品／订单有空态及重新加载。使用项目既有品牌／运营图，字体与OFL许可随包。构建／运行／业务和待核差异见[资产盘点](../../../../项目相关报告/桌面与Web资产盘点.md)。
