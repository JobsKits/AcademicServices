## 🔥 <span id="前言">前言</span>

使用 [**SwiftUI**](https://developer.apple.com/documentation/swiftui) 原生窗口与控件，支持 [**MacOS**](https://www.apple.com/macos/) 13及以上。不需要 Python、Qt或网页运行时。商品与订单使用既有 Go API；平台专用源码可直接修改。

## 一、<span id="run">运行与构建</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

双击 `Dist/知序.app` 运行。修改源码后双击 `构建.command`，阅读自述后回车；构建写入本目录 `Dist/`，不清理其它产物或系统配置。需要本机 Xcode Command Line Tools／Swift。命令行可在本目录运行：

```shell
/bin/zsh ./构建.command --build
open ./Dist/知序.app
```

产物自含JSON、商品图、Logo与字体，可单独复制改名运行；资源内的 `SourceManifest.sha256`／`ResourceManifest.sha256` 分别记录相对源码及资源摘要。本地临时签名已校验，不代表公证或发布签名。构建默认目标是当前宿主架构；Intel Mac另验。

## 二、<span id="source">源码、功能与数据</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 文件 | 职责 |
| --- | --- |
| `Sources/ZhixuMac.swift` | 原生App、顶栏、商品／详情、订单／个人页和业务表单入口 |
| `Sources/ProfileView.swift` | 头像／GIF预览、心情、只读UID、邮箱手机及订单入口 |
| `Sources/NativeForm.swift` | 业务表单、图片选择与主题／语言／连接设置 |
| `Sources/AuthDoor.swift` | 登录／注册／找回三张独立滑动卡片、访客认证占位、演示身份与密码可见性 |
| `Sources/LocalDemoAuth.swift` | 仅本地离线的验证码、注册、登录与密码重置；账号及盐哈希只在内存 |
| `Sources/ShopStore.swift` | 用户状态、API优先、隔离演示、幂等未知写及迟到响应隔离 |
| `Sources/Models.swift` | Codable商城模型、HTTP传输和错误类型 |
| `Info.plist`／`构建.command` | 可重建应用包、系统要求与相对资源定位 |

默认API为 `http://127.0.0.1:8080/api/v1`，超时2500ms，可在设置改为500—10000ms；切换地址退出原会话。进入、刷新与写操作正常请求接口。仅数字回环／localhost并且服务明确 `demo_mode=true`，或本地离线且从未明确为正式服务时显示演示身份；远程不预填演示账号、不开放演示登录回退。可用角色限定当前买方能力，在线身份取服务实际返回的买方凭据；离线可切 `customer`／`customer2`，不冒充管理员工作区。

访客点击“我的订单／个人中心”直接打开登录卡，认证成功进入原目标，取消保留原页面；三门切换不丢目标。认证占位独立于数据空态，以登录为主动作。页脚只保留连接状态与设置；真实列表空态仍可重新加载，原请求重试只在实际未知写状态出现。

三张认证卡以独立空间横向滑入／滑出，左侧轨卡与卡底文字切换，主动作分别为登录、创建账号、重置密码；支持减少动态效果、键盘提交、十语言和三主题。仅本地演示预填所选身份并默认显示密码，眼睛按钮可切密文；普通认证默认隐藏，注册／重置不预填密码。各卡草稿独立且只在当前认证门内存保留，关闭即清除。注册／找回始终先走真实API和邮箱流程；本地网络不可达时同样经过验证码、账号校验和密码一致性完成隔离演示，不把错误密码或401当作成功。

服务拒绝不冒充演示，真实写超时保留原意图与幂等键，重试只发原请求。演示账号、验证码与订单仅在进程内，不上传；关闭应用结束会话，偏好以应用专属 UserDefaults 保存，不保存口令或Token。

三态主题与简繁藏英日法西德俄韩完整界面切换，商家内容保留原文。商品／订单空态均有重新加载；图片先用打包资源，失败保留本地兜底。素材复用项目既有原创品牌／运营图，Noto字体与OFL许可随包。

个人中心点击头像可选择八款随包表情或本地PNG／JPEG／WebP／GIF（20MiB以内），保留原图帧；减少动态效果或应用不活跃时暂停GIF播放。头像下心情默认“慢慢来，每一步都算数。”，前置编辑图标可保存。UID取系统账号ID且只读；邮箱／手机号不验证、不裁剪，按输入原样保存。未验证联系邮箱不改变已验证的登录／找回身份。资料由服务端持久化；本地离线演示资料按身份保留到进程结束，切地址清除，不补传。个人中心订单入口与顶部订单页共用导航；演示标识只在演示环境显示。

右上用户名展开账户下拉，仅有切换账号和红底白字退出；个人页不重复摆放退出按钮。首页主副标题在顶栏同一行、间隔一个空格，轮播高度为原版一半（宽高比1440:280），图片等比显示；窗口最小内容尺寸960×600，继续缩小由原生窗口约束阻止。分类卡片按图标／18pt标题／22pt数量横排，与点击、左右拖动、键盘方向及左右翻页同步。商品整卡均可进入详情，返回带左箭头并恢复分类及滚动上下文。订单去除重复大标题，状态卡片显示当前账号真实数量并与左右内容同步，空态按筛选栏下方的数据区域居中。设置为左对齐分组，取消不保存草稿，连接调试字段只在演示环境显示。

当前构建与业务实测、迁移差异见[资产盘点](../../../../项目相关报告/桌面与Web资产盘点.md)。多图轮播、分类联动与详情返回已按本轮源码及Mac窗口核对；最小阈值边缘拖动、持续GIF播放、全部语言与Windows控件验收仍按盘点分别记账，不能用旧Qt测试代替本端验收。
