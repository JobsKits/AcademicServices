## 🔥 <span id="前言">前言</span>

标准HTML／CSS／JavaScript买方商城，桌面商品网格、手机竖屏和触屏表单，320px起可用；商品／订单／个人中心有独立hash路径。与MacOS／Windows原生桌面为各自独立界面。

## 一、<span id="run">打开与离线预览</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

正常部署直接访问Go服务 `/client/`，API同源 `/api/v1`；八平台部署脚本默认选择本目录，原管理后台保持独立 `/admin/`。无需Node／Flutter构建。`index.html`为入口，`shop.css`负责布局与主题，`shop.js`负责账户、商品／订单和数据仓库，`Assets/`为十语言、种子商品、原创品牌／运营图与许可字体。

没有后端时，在本目录启动任意静态HTTP服务器，例如本机已装Python可运行：

```shell
python3 -m http.server 8088 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8088/`；进入时仍请求同源API，失败使用隔离演示。不能通过file协议双击跨文件ES module与JSON；手机使用正式部署HTTPS地址，不使用手机自己的127.0.0.1。

## 二、<span id="behavior">功能与数据规则</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

商品分类与详情、登录／邮箱注册／找回、购买需求、订单筛选、需求编辑、模拟支付、交付确认与评价、资料／头像、语言／主题／连接设置。三态主题和简繁藏英日法西德俄韩切换，商家内容按原文；键盘焦点、原生dialog与控件标签、触摸目标、手机安全区及长文本换行均由源码维护。

默认超时2500ms，可设500—10000ms。首屏立即呈现本地样例；进入、刷新、写操作均请求API，成功替换为服务端数据，网络失败使用隔离演示；401／403等不冒充成功。离线演示账户 `customer / demo-customer`，密码错误保持拒绝。演示订单不上传；真实写未知保留原意图与幂等键。语言／主题／地址／超时存在localStorage，登录口令／Token不持久化；关闭／刷新页面结束当前会话和演示订单。

所有动态列表提供完整空态和重新加载。商品图失败回退本地品牌，字体随包。原素材来自本项目Python端既有Jobs原创图与Noto字体，OFL许可在 `Assets/Fonts/`；没有新增未知来源素材。实际浏览器尺寸、业务流程及原生迁移差异见[资产盘点](../../../../项目相关报告/桌面与Web资产盘点.md)。

首页轮播读取后台图片与目标链接，未连接时使用随包三分类图；自动轮播与实心／空心分页点手动切换均可用。页面隐藏、减少动态效果、轮播内键盘焦点、鼠标悬停或弹窗打开时暂停自动切换；不显示播放控制或数字页码。网络图片先显示本地品牌，加载成功后替换，失败保留品牌。

读取和写入以账户／服务代次隔离，刷新序号阻止旧列表覆盖新请求或已确认写入。写请求发出前冻结原正文和幂等键，在途只允许一笔；未知结果重试保留原键。动作返回须匹配准确订单并推进版本；关闭、重开或切换表单后，旧请求不关闭新表单。并发回归入口见[Web测试](../../../../测试/前端/PC端/Web/README.md)。
