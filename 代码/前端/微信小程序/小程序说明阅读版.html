🔥 前言

本项目已确认必须交付独立的微信小程序前端。沿用现有官方原生 WXML／WXSS／JavaScript／JSON 工程，零第三方运行依赖，与 Web／H5 分别交付。和其它客户端共用 Go API，覆盖三服务浏览、账户登录、提交、需求详情、报价确认、文件、消息、交付反馈／验收、取消结算确认与售后。

一、打开和连接 🔼 🔽

微信开发者工具导入本目录。project.config.json 使用 touristappid 便于开发预览，基础库 latest 由开发者工具解析；本机尚未运行开发者工具验证具体基础库版本。正式发布填写自己的AppID，使用最新稳定开发者工具，并在管理后台配置API的HTTPS合法域名。

“账户与连接”中填写完整API地址。本机工具可连接 http://127.0.0.1:8080/api/v1；真机必须使用可访问的HTTPS服务器域名，不能用电脑的loopback地址。开发账户按钮会尝试真实customer演示账户，密码被正式配置替换后须手动输入自己的密码。

同页可配置请求超时，范围 500—10000 毫秒，默认 2500 毫秒；设置与 API 地址保存在本机，普通请求、上传和下载共用此值。未部署服务时可快速进入隔离演示，恢复后的成功响应自动采用真数据；切换连接设置会清空现有会话，需重新登录。

二、业务和恢复 🔼 🔽

游客可读三服务，提交前登录。毕业论文要求专业/学历，普刊要求专业，编译要求语种，所有需求要求标题、说明与处理授权。附件从聊天文件选择，每次上传新文件，服务端限制8MB。通过授权下载接口预览文件，当前格式无法打开时提示改用桌面下载。

真实提交与演示共用必填和材料处理授权校验，字数只接受非负整数。服务、需求列表以及详情的暂停、待确认变更、交付、附件和沟通记录均提供空态与重新加载；重复刷新时忽略较早请求的迟到结果，防止真数据被旧响应或旧演示覆盖。

读失败回退隔离演示，真实空列表不填假数据。401撤销会话并清私有缓存；403/409/422显示真实拒绝。未知真实写入保留原键与正文、阻止重复写，列表提供核对入口；404尚未找到收据不视为在途请求已经失败。本地待核对资料按API地址与账户分开保存，不保存密码/会话Token；设备使用者仍应保护应用存储。

离线演示仅支持新建、留言、补说明与撤回，复杂资金及正式文件动作须连接后端。样例不自动上传。全量管理动作由Flutter管理后台提供，小程序不作为管理员入口。

三、验证与限制 🔼 🔽

仓库逻辑可在工程根运行：

node --test './测试/前端/微信小程序/test_mini.cjs'

包含空结果、网络恢复、鉴权清缓存、真实未知写入核对、换号与同账户迟到响应、短超时设置和表单校验等保护。WXML／JS 自动检查不等于微信开发者工具编译或真机验收；当前未做微信登录、手机号授权、在线支付、订阅消息或平台提审。交付时分别登记源码导入与工具编译、iOS／Android 微信真机业务、体验版、提审与正式发布的结果；所选基础库、AppID、账号主体和 HTTPS 合法域名仍须实际验证。
