## 🔥 <span id="前言">前言</span>

采用[**微信小程序**](https://developers.weixin.qq.com/miniprogram/dev/framework/)官方原生 JavaScript／WXML／WXSS／JSON，零第三方运行依赖，与其它客户端共用商城 API。唯一首页为商城；毕业论文、普刊、编译三分类含九个课程／服务商品及独立详情，课程与服务均为虚拟商品。

## 一、<span id="open">打开与连接</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 微信开发者工具导入本目录。配置使用 touristappid 供开发预览；正式项目填写自己的 AppID 并配置 HTTPS 合法域名。当前没有执行开发者工具编译，基础库的实际解析版本需在工具中核验。
- 设置页维护完整 API 地址（含 /api/v1）和请求超时（500—10000 毫秒，默认2500）。开发者工具可用 http://127.0.0.1:8080/api/v1，手机必须使用手机可达的 HTTPS 地址；更改连接会退出当前会话。
- 账户页登录 customer 测试账户；“本地演示”按钮仍先请求开发账户的真实登录。网络异常才进入隔离演示，密码错误／权限拒绝不会变成成功。正式配置替换开发密码后使用自己的账户密码，密码和 token 不写本地永久存储。

## 二、<span id="purchase">购买、付款及订单</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 分类页和详情展示名称、价格、简介、详情分节和库存；已下架或缺货无法新购。下单传商品版本，金额以服务端快照为准，历史订单不随后台改价变化。
- 下单后进入待付款订单，弹出支付宝／微信渠道收银台；关闭不付款，主动点击确认才模拟成功。收银台明确提示不会扣款，订单保留渠道、金额与 MOCK 标记。无商户 Key 时不生成官方支付单，不声称已唤起有效官方付款流程。
- 订单支持全部、待付款、待完成、待评价、已完成筛选。未付订单可取消；站方通过管理端开始服务和提交交付，买方在已交付后确认完成，再评分／填写评价。不存在物流及签收流程，小程序不提供站方履约权限。
- 商品、订单和详情失败态均提供完整无数据组件和重载。商品图先展示打包品牌图，再覆盖后台商品图；异步图失败保留品牌图，重载后允许再次加载。品牌资源复用仓库自有 icon.png，未下载或冒用参考站宣传素材。

## 三、<span id="recovery">服务优先与写入恢复</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 每次进入、重载与写操作均请求 API；网络、超时或响应无法解析时使用隔离演示数据。后续成功响应自动回真实数据，真实空列表保持空态。
- 本地演示的订单仅保存在当前会话，不自动上传；退出清除私有缓存。服务恢复后如演示身份尚无真实 token，需正常登录才能读取真实私有订单。
- 真实写请求结果未知时，不报告本地付款成功：保存原提交键与正文，阻止再次下单，订单页可按原键核对收据或重试；404 未查到收据不解除阻塞。待核对记录按 API 与用户隔离保存，不含密码／token。
- 401 清会话和私有显示；403／409／422显示拒绝，版本冲突需重载后确认。仓库写锁防止并发双下单，旧请求不能覆盖新会话或更新版本。

## 四、<span id="preferences">语言与主题</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

设置页支持简体中文、繁体中文、藏文、英文、日文、法文、西班牙文、德文、俄罗斯文、韩文，支付与订单文案同步切换；后台输入的动态商品与交付内容保持原输入语言。白天、黑夜、跟随系统三主题可用，系统模式监听主题变化；偏好保存在设备本地。主界面使用米白、暖棕和低饱和卡片，深色保留暖深底与易读对比。

## 五、<span id="validation">验证及限制</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

在仓库根运行：

```shell
node --test ./测试/前端/微信小程序/test_shop.cjs ./测试/前端/微信小程序/test_mini.cjs
```

当前仓库逻辑测试44项通过（商城24项、HTTP及幂等20项）；源码语法和页面资源检查通过。未执行微信开发者工具编译、iOS／Android微信真机、微信身份／手机号授权、外部真实支付、订阅消息、体验版、提审和发布，不能用 Node 测试代替设备验收。真机需验证布局、暗色、十语言字体与键盘、网络恢复和模拟购买闭环。
