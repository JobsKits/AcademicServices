🔥 前言

本图定位 Flutter 移动用户端与本工程承载的共享 zhixu 包；Dart 业务在 lib/。ios/、android/、web/ 是本工程平台壳，不是另建的业务实现。路径均从当前文档相对指向源码；跨单元内容只通过链接引用。

一、入口与模块职责 🔼 🔽

本单元路径 职责
lib/main.dart 用户商城入口，启动 ShopApp。
lib/Shop/app.dart 商城分类、商品详情、收银台、订单、后台编辑、暖色三主题与设置。
lib/Shop/repository.dart 商品与订单 API、模拟演示、权限、原键重试及响应隔离。
lib/Shop/strings.dart 十语言商城界面文案。
lib/Data/repository.dart API、身份、样例隔离、未知提交与原键核对。
lib/Data/models.dart 客户端数据模型。
lib/Ui/app.dart 响应式页面与用户／管理员模式的共用界面。
lib/Ui/actions.dart 角色／阶段动作表单。
lib/Ui/theme.dart 主副文字、背景与主题。
pubspec.yaml zhixu 包名、依赖与平台资源配置。
Tool/prepare_harmony.py 为独立鸿蒙宿主准备用户 Web 与端点配置；不代表已构建 HAP。

二、本单元关系 🔼 🔽

flowchart LR
    Main[lib/main.dart 用户入口] --> App[Shop/app.dart]
    App --> Text[Shop/strings.dart]
    App --> Repository[Shop/repository.dart]
    Repository --> Models[Data/models.dart]

三、共享源与外部依赖 🔼 🔽

  • 后台 Flutter 地图：后台通过 path 包依赖复用本工程的数据、主题和界面，独立入口由后台维护
  • 鸿蒙宿主地图：宿主通过 HTTPS 加载本工程的用户 Web
  • 唯一接口契约：与其它客户端共用同一个 Go API
  • Go 后端地图：由 Go 服务托管用户 Web 和 API
