## <span id="section-2">二、多轮发现与修正</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

1、首轮业务与客户端测试建立基线。小程序迟到账户回包保护未正确拒绝，修正后原10项通过。桌面首次冻结包漏收Qt平台插件，改为显式随包，并将真实APP启动作为发布DMG前门禁。

2、整合HTTP前两轮暴露测试夹具口径：每条用例重复登录触发真实每IP限流；创建/上传实际成功为201，夹具原只接受200。改为同套会话复用、按接口接纳201，不关闭业务限流；第三/第四轮14项全过。首次失败日志保留，未将夹具问题记为后端业务缺陷。

3、客户端深入回归补了真实/演示、未知提交、账号隔离和坏响应。桌面修复下载/核对401/403未清私有状态及畸形description；小程序清理读失败时真实缓存，保留跨会话原键/原正文，阻止选文件期间换号后继续上传。

4、独立部署审计复现“悬空配置链接先被写入再拒绝”，已把链接检查提前，并拒绝链接运行目录。Mac/Ubuntu复测均未向外部目标写入；新增夹具纳入正式13项。Go模块及构建缓存限定工程内，遥测关闭。

5、Flutter交互测试补出弹窗退出动画仍读取已释放controller，改为等待路由退出完成再释放。三服务表单按类别显示必填项，字数/日期保持选填，附件上限统一8MB；资金表单按退款阶段选择，unknown核对失败单独办理。

6、鸿蒙原本地file来源与生产CORS存在不兼容，改为明确同源HTTPS宿主，首启失败展示说明与重试。未通过允许任意Origin或忽略证书错误规避问题。

7、浏览器真实可视流程：客户创建编译需求，管理员刷新看到同编号并发布100元报价，客户刷新接受，双方进入待开始订单、版本1→2→3，真数据来源提示正确；手机390宽布局、空态与首页已有截图。该流程只使用独立本机合成数据，不涉及真实商业合同或资金。

## <span id="section-3">三、尚未通过的目标环境</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- **Android APK/AAB**：最新AGP/Gradle/Kotlin/API/NDK配置已落，多轮先遇Maven/Java TLS错误，最后推进至NDK30官方下载时因Premature EOF中断；以Flutter最新 `validation-summary.json` 为准，不把构建进行中当成功。未生成APK时没有可分发Android成品。
- **鸿蒙HAP/APP**：缺DevEco、SDK和签名，未实际编译、安装；HTTPS宿主与附件能力仍需真实ArkWeb验证。离线首启无法加载线上页面。
- **Windows桌面/服务器**：PowerShell解析和隔离逻辑检查不等于Windows实际EXE打包/运行或服务部署；Intel Mac也待目标机。
- **iPhone Duo**：窗口、字体、安全区及iOS构建已有证据，折叠姿态、窗口连续性、键盘、真实文件与签名安装未完成设备验收。
- **原生PostgreSQL**：已验证PGlite协议夹具和PG驱动，不等于原生PG故障、性能、恢复或生产迁移通过；29表仍未逐表接业务。
- **完整生产业务**：真实客户身份、员工授权、微信登录/支付、通知发送、普刊外部反馈、对象存储、容量/灾备/商店提审尚未完成。
