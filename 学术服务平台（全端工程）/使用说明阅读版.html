知序｜从第一次打开开始

前言一、最快体验完整流程二、只想先看桌面软件三、手机和小程序怎样打开四、看到这些状态时怎样处理五、取消、退款和售后例子六、常见启动问题

🔥 前言

本工程是覆盖前后端的可运行联调版，品牌暂称“知序”。普通操作者先用浏览器或已生成的桌面应用体验；开发者再看工程总览。本轮不要求操作者手写代码。正式客户注册、微信身份接入、员工细分权限与收付款渠道仍需继续开发。

一、最快体验完整流程

1、打开工程中的 backend/deploy，选择当前操作系统的文件夹。Mac 双击 macOS/部署.command，Windows 双击 Windows/部署.cmd。Linux 桌面可双击对应文件夹的 双击部署.desktop；系统须允许启动该文件，纯命令行服务器使用下章的命令。

2、阅读终端自述并回车。缺少 Go 时，脚本显示官方下载地址和目标位置，回车安装到工程内；输入其它字符取消。已有健康环境直接复用。初次下载需联网，网络不通会停止并给日志位置。

3、监听地址先直接回车，采用 127.0.0.1:8080，只允许本机访问。分别设置管理员和客户密码，各至少12个字符，二者不能相同。密码输入时不显示字符属于正常行为。数据库连接串直接回车，使用本机文件存储。

4、看到“academic service ready”后保留终端窗口。浏览器打开 客户页面 和 管理后台。在客户页用 customer 和刚设置的客户密码登录，在管理页用 admin 和管理员密码登录。页面给出的开发演示密码不适用于这个生产配置入口。

5、客户选择毕业论文、普刊或编译，填写需求并提交。管理员刷新列表、打开同一需求，先补材料或创建报价。报价中的范围须写清交付内容、周期、修改及取消规则；界面金额输入框使用“元”，输入 100 为100元；接口内部自动换算为整数分。

6、客户确认报价后生成订单。若报价约定启动款，管理员先核对实际收款凭据再登记，达到门槛才能开工。没有接入银行或微信自动扣款，点击“登记收款”只记录已核实事实。

7、管理员上传交付附件并发布正式交付。客户可绑定该版本提交修改意见；管理员受理时选计次0或1、确认轮次，再发布新版本。客户确认最新正式版后订单完成。完成后另建售后，保留原订单完成记录。

8、结束体验，在服务终端按 Ctrl+C。数据保存在 backend/data，再次运行原脚本会保留配置与数据。先退出再复制整个数据目录做备份；保留配置文件，避免恢复后不知道账户密码。

二、只想先看桌面软件

macOS 本机成品在 clients/desktop/知序.app，安装包入口为 知序.dmg。将完整桌面目录一起移动可保持相对快捷入口；发给其他人只需实际APP或DMG。该包包含Python和依赖，普通使用不必另装Python。当前成品为Apple Silicon版本，Intel需要在对应Mac重新构建。

Windows 需要在Windows本机双击 clients/desktop/【Windows】📦生成exe.bat，成功后使用生成的EXE目录或ZIP；当前没有经过Windows本机验证的EXE成品。源码体验可运行同目录 【Windows】启动知序.bat，Mac也有对应启动入口，缺失依赖会在确认后准备。

打开桌面应用，在设置中填写完整API地址。与后端同一电脑使用 http://127.0.0.1:8080/api/v1；其它电脑需要可访问的服务器HTTPS地址。使用相同customer账户，各端看到同一份后端记录。白天、黑夜、跟随系统可在设置切换。

三、手机和小程序怎样打开

目标 当前入口与操作
iOS / iPhone Duo clients/flutter/ios，用自己的Apple团队签名后安装；无签名Release构建已验证，未做Duo实机验收
Android clients/flutter/android，按模块README构建APK或AAB；发布须配置自己的keystore，最新SDK构建结果见回归报告
鸿蒙 clients/flutter/harmony，ArkWeb宿主加载HTTPS Flutter用户页面；使用DevEco与自己的签名构建HAP/APP，当前尚未实编
微信小程序 微信开发者工具导入 clients/miniprogram；本机可用测试AppID预览，发布前填写自有AppID并配置HTTPS合法域名
手机浏览器体验 部署好HTTPS服务器后打开 /client/；管理人员打开 /admin/，窄屏会调整导航与详情布局

手机的 127.0.0.1 指手机自身。电脑启动的服务必须通过手机可访问的服务器域名连接；正式HTTPS、域名、证书和签名不是一个源码包能自动取得的账户资料，需部署方提供。iOS、Android原生包必须在构建时使用正式API地址，详见Flutter说明。

四、看到这些状态时怎样处理

页面提示 应做的事
服务端 / 已连接 此次成功响应来自后端，查看记录编号与版本
本地演示 当前数据仅用于体验，不视为真实提交、到账、上传或退款；样例不会自动上传
结果待确认 / 待核对 保留原操作，点击“查询原操作”；仍未查到时稍后再查，或按原键原正文重试。不要重新创建同一资金动作
401 / 登录失效 重新登录；旧账户的私有资料会清除
403 当前账户无权办理，切换有权限的账户
409 / 版本冲突 重新加载最新状态后核对，不能用旧界面覆盖别人的操作
422 按提示补齐或修正输入
暂无需求 / 暂无文件 当前真实列表为空，可重新加载；不会用假订单填充
退款待审核 / 已批准 / 待核对 钱尚未记为已退回；管理员核实原流水后才登记成功

读取失败时客户端可展示隔离演示，后续成功响应自动替换为真数据。真实写入超时不当作失败重做。Flutter和桌面会按账户与服务器保存待核对正文与原键；本地记录不含密码或令牌，仍应保护共享电脑。小程序保留待核对记录并提供查询入口。

五、取消、退款和售后例子

订单原价1000元，已收300元，双方同意取消后的最终应收100元。管理员提出取消结算100元，客户确认后订单取消。管理员关联原收款申请退款200元，批准后先占用额度；核实退款成功再登记凭据，净收款为100元。原价与结算价都保留，不能继续按原价催收900元。

退款未知时先核对原流水；不要直接标失败再换号退款。完成或取消的订单可新开售后，退款义务与结算差额未清时，后台会阻止关闭售后。

六、常见启动问题

  • 端口已占用：先停止正在使用同一端口的服务，或把 .runtime/config.env 中的 LISTEN_ADDR 改为其它本机端口。浏览器地址相应修改。
  • 数据目录已锁定：先确认旧服务确实停止，备份数据目录，再处理 .server-lock。不要删除 state.json，不要让两个文件模式实例共用目录。
  • 下载失败：保留日志，确认服务器能访问官方Go下载和模块源后重试；脚本不更改代理或关闭证书校验。
  • 后台文件缺失：复制完整 backend，包括 admin-web 与 client-web；只复制Go源代码不会自动生成Flutter页面。
  • Mac提示来源未识别：当前包尚未开发者签名与公证。正式分发应完成签名公证；不要自动关闭系统安全机制。
  • 小程序真机连不上：核对AppID、服务器HTTPS域名、开发者工具/微信版本和基础库；不以关闭合法域名校验当作发布方案。
  • 脚本执行位在拷贝时丢失：Mac/Linux在终端显式运行 zsh 部署.command 或 bash deploy.sh；路径可拖进终端，保留完整引号。
