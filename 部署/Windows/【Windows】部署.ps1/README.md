# Windows 部署入口

部署与反部署的生命周期核心分别内嵌在本平台两份脚本中，覆盖原点、操作锁、进程身份、数据备份和资源恢复；两份脚本可分别执行，无须加载外部生命周期函数库。确认顺序、状态协议、数据策略及恢复边界见[原点与恢复协议](../../README.md#lifecycle-protocol)。

本包承载唯一部署实现；平台目录中的 [【Windows】双击部署（快捷入口）.cmd](../【Windows】双击部署（快捷入口）.cmd) 与同级 [CMD 启动器](../【Windows】部署.cmd/【Windows】部署.cmd) 均使用此处的部署逻辑。

保持根目录的 `代码/` 与 `部署/` 并保留原相对层级 与两个同级脚本包；CMD调用原生Windows PowerShell，未安装Node/Python/Homebrew。正常部署预算为64位2核、4 GiB可用内存、20 GiB空闲SSD；图形整机至少8 GiB，数据增长另计。

**扫码访问：** 地址生成后仍逐行显示完整 URL，并分别生成用户端、管理端的本地二维码。支持颜色且足够宽的终端直接显示黑白码；窄终端、非 TTY、`NO_COLOR` 或 Windows 纯文本环境，打开日志列出的 `.runtime/access-qr.*/index.html`（Windows 为 `access-qr-编号`）扫码，可保存 SVG/PNG。二维码不经过在线服务；隧道地址变化会重新生成，退出时页面标记失效。服务器可通过环境变量或 `.runtime/config.env` 的 `PUBLIC_BASE_URL=https://实际域名` 指定不含账户、查询参数或片段的基地址；未配置时仅显示明确标为“仅本机”的回环入口，手机无法访问。二维码辅助失败只告警，原 URL 与健康服务保留；产物由既有反部署清单管理。详见[二维码输出、固定依赖与使用边界](../../公共组件/地址二维码/README.md)。

## 本地部署＋内网穿透

**关闭此运行终端，服务将结束**。本地临时模式在确认公开前及地址生成后的运行日志中单独显示此提示；支持颜色的终端使用红色加粗，非终端、`TERM=dumb` 或 `NO_COLOR` 时显示纯文本，日志不含颜色控制码。当前窗口管理本次后端与隧道，关闭终端或按 `Ctrl+C` 结束本次临时服务，业务数据与账户配置保留。

从本包目录开始，PowerShell运行：

```powershell
powershell.exe -NoProfile -File '.\【Windows】部署.ps1' -Check
powershell.exe -NoProfile -File '.\【Windows】部署.ps1' -Plan
powershell.exe -NoProfile -File '.\【Windows】部署.ps1'
```

阅读自述回车，fzf选“本地部署＋内网穿透”或“服务器部署”；取消/空/非法结果不启动业务。健康现有工具复用；缺少时按锁清单下载原生资产并校验SHA256，不改全局PATH/执行策略/防火墙/自启。首次两个密码不同且至少12位，数据库留空为本机文件存储。

本地模式确认公网后先检查本次后端健康，再建免费Cloudflare Quick随机HTTPS，无需账号/域名。服务器模式不建隧道。Windows ARM64当前无锁定cloudflared原生成品，不能当x64下载安装；先核健康原生工具或按平台文档使用cpolar备选。Ctrl+C只回收本次Process对象，保留数据。

Quick无SLA、地址会变、200在途、无SSE，大陆需实测。端口学术8080、维修8098，每项目独立HTTPS整站同源，保留公网Host。以移动网络验health、真实登录写入重读和私有文件权限；页面演示不算通过。详细cpolar/固定域名、日志和备份见[Windows说明](../README.md#local-tunnel)。


## 部署原点与反部署

部署变更前由本脚本内嵌的原点函数保存原文件、摘要、权限及数据归属；封存实际产物后可由 [反部署快捷入口](../【Windows】双击反部署（快捷入口）.cmd) 进入。先关闭部署运行窗口，默认备份完整数据和匹配配置；后续变更、共享未知对象、外部数据库或缺少原点均保留并停止。完整规则见[反部署说明](../【Windows】反部署.ps1/README.md)。跨操作系统的原点不能相互覆盖。
