## 🔥 <span id="前言">前言</span>

本目录集中放置多个系统部署入口共同使用的地址二维码实现与资源。`部署/` 根目录的操作系统文件夹负责平台入口；公共组件不作为独立平台，不移动或复制各系统的部署逻辑。分发时保留完整 `代码/` 与 `部署/` 相对结构。

## 一、<span id="components">组件与职责</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 组件 | 职责与边界 |
| --- | --- |
| [地址二维码](./地址二维码/README.md) | 共用的离线二维码工具与固定依赖，生成用户端、管理端 URL 对应的终端码及本地页面、SVG、PNG；由各系统入口调用。 |

各平台部署与反部署脚本分别内嵌生命周期核心，原点与恢复由各自脚本维护。二维码组件从调用方传入的项目根和运行目录解析资源，不依赖启动工作目录。源码与锁文件留在本目录，运行产物仍在后端 `.runtime/` 中，由既有部署与反部署资源清单管理；目录调整不改变服务、数据或运行状态位置。
