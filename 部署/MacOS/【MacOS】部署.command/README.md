# MacOS 部署入口

部署与反部署的生命周期核心分别内嵌在本平台两份脚本中，覆盖原点、操作锁、进程身份、数据备份和资源恢复；两份脚本可分别执行，无须加载外部生命周期函数库。确认顺序、状态协议、数据策略及恢复边界见[原点与恢复协议](../../README.md#lifecycle-protocol)。

此目录与实际脚本同名；直接运行本目录内的同名脚本。复制根目录的 `代码/` 与 `部署/` 并保留原相对层级，不能单独移动这个脚本包。

在上一层平台目录可直接双击 [【MacOS】双击部署（快捷入口）.command](../【MacOS】双击部署（快捷入口）.command)；快捷入口调用本包内的部署实现，复用自述与确认。

部署在写入前记录资源原点、原件与进程身份，退出时保留恢复清单。撤回本工程部署使用[配对反部署脚本](../【MacOS】反部署.command/README.md)，默认校验备份数据后清源；原有共享环境、后续变更和缺少依据的旧部署保留并报告。共同运行资料由跨平台归属锁保护，不能在另一平台强行覆盖清单。

**扫码访问：** 地址生成后仍逐行显示完整 URL，并分别生成用户端、管理端的本地二维码。支持颜色且足够宽的终端直接显示黑白码；窄终端、非 TTY、`NO_COLOR` 或 Windows 纯文本环境，打开日志列出的 `.runtime/access-qr.*/index.html`（Windows 为 `access-qr-编号`）扫码，可保存 SVG/PNG。二维码不经过在线服务；隧道地址变化会重新生成，退出时页面标记失效。服务器可通过环境变量或 `.runtime/config.env` 的 `PUBLIC_BASE_URL=https://实际域名` 指定不含账户、查询参数或片段的基地址；未配置时仅显示明确标为“仅本机”的回环入口，手机无法访问。二维码辅助失败只告警，原 URL 与健康服务保留；产物由既有反部署清单管理。详见[二维码输出、固定依赖与使用边界](../../公共组件/地址二维码/README.md)。

## 最低机器配置

正常脚本编译部署预算：64位2核、4 GiB可用内存、20 GiB空闲SSD；图形主机整机至少8 GiB。数据、附件、日志增长另计，未作容量实测。

## 本地部署＋内网穿透

**关闭此运行终端，服务将结束**。本地临时模式在确认公开前及地址生成后的运行日志中单独显示此提示；支持颜色的终端使用红色加粗，非终端、`TERM=dumb` 或 `NO_COLOR` 时显示纯文本，日志不含颜色控制码。当前窗口管理本次后端与隧道，关闭终端或按 `Ctrl+C` 结束本次临时服务，业务数据与账户配置保留。

从本目录开始：

```zsh
zsh './【MacOS】部署.command' --check
zsh './【MacOS】部署.command' --plan
zsh './【MacOS】部署.command'
```

阅读自述回车后，fzf选“本地部署＋内网穿透”或“服务器部署”；取消/空选/错误不启动业务。缺少fzf/Go/cloudflared时按工程锁清单准备官方原生资产并验SHA256；健康现有工具复用，不升级全局环境。本地模式先配置不同的非默认密码，默认文件存储、127.0.0.1:8080，确认公网后由脚本先验本次后端健康，再建免费Cloudflare Quick随机HTTPS；无需账号或域名。服务器模式只运行后端，不建隧道。

密码隐藏输入：本地调试至少4个字符，服务器部署至少12个字符；不足长度或使用演示默认值时持续重问当前账户，客户密码与管理员相同时只重问客户密码。已有本地短密码切到服务器模式时，只重新设置不合规密码并原子保存，其它配置和数据保留；按 `Ctrl+C` 或输入结束可取消，未完成的密码更新不会保存。

本地模式仍会建立公网临时地址，只用于指定测试者的临时调试。短密码许可只对本次本地后端进程生效，并由后端校验回环监听；服务器模式自动清除调试许可，继续要求12个字符。

公网地址生成后，用户端、管理端分别显示标题与独占一行的完整地址，直接选择整行即可复制。支持颜色的终端中标题为黄色加粗、地址为绿色加粗；非终端、`TERM=dumb` 或设置 `NO_COLOR` 时显示纯文本，日志始终不含颜色控制码。

本地模式按 `Ctrl+C` 或入口收到终端关窗信号 `SIGHUP` 时回收本次后端和隧道，数据保留；不会按进程名/端口停止其它服务。Quick无SLA，大陆网络需实测，地址会变，200在途且不支持SSE。45秒无地址会停止并提示排查。FreeBSD/ARM64和Alpine的原生工具/ABI限制按平台说明核对，不下载错架构。

文件模式由后端数据目录内持久 `.server-guard` 的系统文件锁保护，同一数据目录只能有一个实例；guard 文件保留，不要手工删除。遗留 `.server-lock` 只有记录有效、旧 PID 明确已不存在且文件复核一致，才先备份为同目录的 `.server-lock.stale-*.bak` 再恢复启动；活进程、损坏或不明记录、符号链接均停止并保留。配置与 `state.json` 不参与锁回收。本地后端启动失败时，终端会显示最近12行脱敏诊断，完整原始日志保留在本次日志名追加的 `.server.log` 中；分享日志前仍须脱敏。具体路径与排查见[本平台说明](../README.md#local-tunnel-troubleshooting)。

双项目端口为学术8080、维修8098，各用独立HTTPS整站同源入口；保留公网Host，不重写localhost。必须用手机移动网络验health、真实登录/写入刷新重读/私有文件权限，演示页面不代表服务连通。详细cpolar备选、固定地址、日志、停止与备份见[本平台说明](../README.md#local-tunnel)。
