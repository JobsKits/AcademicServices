| 生命周期核心（[部署入口](../【MacOS】部署.command/【MacOS】部署.command)／[反部署入口](../【MacOS】反部署.command/【MacOS】反部署.command)） | 两份脚本各自内嵌原点、互斥与恢复实现；不依赖外部生命周期函数库。 |

部署入口的 `preselect_existing_mode` 在接管前完成只读模式选择；`acquire_restart_lock` 与 `stop_previous_deployment` 串行停止身份匹配的旧实例。`start_session_guard`／`run_session_guard` 监测部署入口及终端父进程，`run_session_child` 在启动业务前自登记并管理后端／隧道子进程；`cleanup_owned_processes` 与 `finalize_deployment_before_exit` 完成回收、日志／二维码封存和解锁。两份脚本的 `lc_manifest` 使用 `runtime-selected` 范围封存本轮资料，退出时不遍历 SDK 缓存。

当前依赖链：`prepare_latest_dependencies`、`prepare_dependency_resolver`、`resolve_latest_dependency`、`ensure_latest_dependency`、`accept_latest_dependency`；`check_business_dependency_updates`；`build_locked_module`；外置缓存子收据由 `lc_cache_begin`／`lc_cache_seal`／`lc_cache_restore` 管理。静态锁只作Bootstrap，模式确认后核查官方最新稳定Go／fzf及本地模式cloudflared；源码业务锁只读报告，超时不称已检查，按锁构建并复核源文件不变。共享元数据与报告合同见[依赖解析组件](../../公共组件/依赖版本/README.md)，具体缓存目录见[平台说明](../README.md#latest-dependencies)。

