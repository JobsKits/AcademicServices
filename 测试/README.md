## 🔥 <span id="前言">前言</span>

本目录集中保存各端测试源码、测试计划、执行报告与证据，与 `../代码/`、`../需求/` 同级。[**Go**](https://go.dev/)、[**Flutter**](https://flutter.dev/)、桌面及整合测试不在核心代码目录保留副本。历史报告保留原日期；当前源码、测试执行、平台构建、真机业务和正式发布分别登记。

代码、测试、需求三个资料主目录的一级仅保留 `README.md` 与子目录；文档原稿、同主题阅读版及附件按职责或标题集中，入口由本页导航。

当前商城执行证据及MC场景见[商城回归](./商城回归/README.md)，包含商品管理、双渠道模拟支付、交付确认评价、权限并发及各端界面。

## 一、<span id="entry">测试入口与范围</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

在仓库根目录运行：

```shell
python3 './测试/运行测试.py/运行测试.py' --list

python3 './测试/运行测试.py/运行测试.py' \
  --group mini \
  --group desktop
```

分组包括 `go`、`desktop`、`http`、`deploy`、`mini`、`flutter`、`harmony`；可重复 `--group`，`--group all` 显式选择全部。需要已有工具与依赖，不自动下载、安装或真实部署。缺少工具明确返回阻塞，跳过项以用例日志为准。完整参数、运行副作用与日志说明见[统一入口](./运行测试.py/README.md)。

## 三、<span id="evidence">证据与验收口径</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>
