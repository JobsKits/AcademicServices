## 三、<span id="rerun">复跑入口</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

在仓库根执行，只使用现有工具链，不自动安装依赖或发布服务：

```shell
python3 './测试/运行测试.py/运行测试.py' --group go --group http --group desktop --group mini --group flutter
```

统一入口及依赖说明见[测试入口](../运行测试.py/README.md)。后端测试通过Go overlay注入外置测试；HTTP启动专属临时Go服务并在退出时清理本次进程；桌面采用Qt离屏，Flutter为仓库／Widget测试，小程序为Node逻辑／页面测试。目标设备、正式渠道和发布不包含在此命令中。
