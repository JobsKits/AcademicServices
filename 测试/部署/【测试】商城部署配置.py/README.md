# 商城部署配置隔离回归

在本目录运行 `python3 './【测试】商城部署配置.py'`；也已纳入项目统一 `--group deploy`。仅测试宿主需要Python 3、zsh、bash、sh及PowerShell 7，部署交付入口继续只使用各平台原生Shell／PowerShell。

52个用例从八个平台真实入口提取配置函数，在中文、空格及改名临时目录、工程外工作目录执行，验证本地强制Demo及模拟支付、服务器清除继承的Demo开关、当前商城双端构建包优先与独立缺包回退。对配置、业务数据和静态页面执行前后哈希比对，断言不写入开关、不覆盖文件、日志不打印测试密码。八份入口均按目标Shell或PowerShell Parser检查语法。

Windows另执行真实`Main`函数，所有安装、编译、启动、隧道和生命周期操作均由夹具替代，分别验证成功及构建失败、原环境存在及未设置时，`DEMO_MODE`／`PAYMENT_MODE`都精确恢复。缺少PowerShell会明确跳过，不能计为Windows行为通过。

不运行真实部署，不安装依赖、不启动项目服务、不发布公网、不停止现有进程。跨宿主PowerShell及Shell隔离行为不代替八系统原生部署验收。单独运行输出到终端；统一测试入口将日志保存在`../证据/本轮/`。
