# Windows 反部署隔离验证

在当前目录运行：

```powershell
pwsh -NoProfile -File '.\【Windows】验证反部署.ps1'
```

也可使用 Windows PowerShell 5.1 的 `powershell.exe`。脚本在系统临时目录创建唯一夹具，提取实际部署和反部署入口标记内的生命周期函数块、比较一致后只加载函数定义，不运行真实 `Main`；结束后仅清理自己的临时夹具，不运行真实后端、不下载依赖、不触碰当前项目运行数据。

- 覆盖默认备份、匹配配置、备份后清源、原配置恢复、共享 SDK 保留、本次新建 SDK 清理、明确清零、重复执行。
- 覆盖原有数据保留、后续产物修改、未知共享文件、外部 PostgreSQL 阻断、备份位置冲突/失败、数据偏离快照、活操作锁、已记录死进程标记/未知标记、跨系统原点、无原点旧部署；还覆盖原子文件恢复中断窗口和完全空白工程回退。
- 验证两个交付脚本都已内嵌同一组原点函数且旧模块目录不存在；解析实际 PowerShell 语法，选择器从反部署入口的 AST 精确提取；夹具支持中文和空格路径。

MacOS 上的 `pwsh` 结果只证明语法与隔离文件逻辑。Windows 控制台双击、交互键位、NTFS ACL、原生进程身份、真实数据库和中断的实机验收须分别执行，不以此结果冒充全平台通过。
