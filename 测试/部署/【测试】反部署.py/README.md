## 🔥 <span id="前言">前言</span>

使用 [**Python**](https://www.python.org) 标准库从各平台真实脚本的内嵌标记提取生命周期函数，在临时目录运行这些函数及假选择器，核对资源归属、数据去向与恢复重试；不执行真实入口的 `main`，不会安装依赖、调用真实数据库或反部署正在使用的工程。

## 一、<span id="run">运行方式</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

在本目录运行：

```shell
python3 './【测试】反部署.py'
```

在项目根执行完整部署回归：

```shell
python3 './测试/运行测试.py/运行测试.py' --group deploy
```

需要已有 `python3`、`sh`、基础文件命令和一种 SHA256 工具；可用时额外验证 `bash`、`zsh`。脚本主动启动测试，无安装步骤或交互确认。临时测试终端和假选择器由用例管理，超时会结束本用例启动的进程。

## 二、<span id="coverage">覆盖范围</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

| 场景 | 核对结果 |
| --- | --- |
| 各平台自包含 | 七系统部署／反部署共十四份内嵌函数块一致，无旧函数库目录；临时提取块可由 `sh`／`bash`／`zsh` 加载 |
| 真实反部署入口与既有协议 | 七系统只复制自身平台目录，用既有 POSIX owner／清单执行 `--check`／`--plan` 与非交互取消；系统识别使用精确替身，不冒充原生系统验收 |
| 旧原点继续使用 | 独立构造既有 TSV 清单及原件，部署内嵌实现继续封存，反部署内嵌实现恢复原件，不更改状态格式 |
| 原有程序、配置、共享工具 | 恢复原程序／配置，保留原有工具；新建归属工具可回收，重复恢复可核对 |
| 后续修改、未知文件、符号链接、损坏副本 | 保留对象并返回未完成，不覆盖后来内容或链接目标 |
| 文件业务数据备份 | 备份包含业务状态、内嵌附件及当前账户配置；摘要验证后才清源，备份目录为私有权限 |
| 备份失败、备份中源变化 | 原数据保留；原备份不被重新生成的快照替代，不继续清零 |
| 中断与重试 | 原确认快照沿用；移动后的隔离源仍可定位，重试继续同一恢复包 |
| 取消与危险确认 | 自述取消、选择器取消／空选／错误／非法结果、未按空格均无业务写入；清零必须明确选择并复核 |
| 进程身份 | 真实存在但身份不符的 PID 不被发送停止信号 |
| 日志与异常封口 | 本次日志允许增长，旧临时配置的后来改动不能被认领；构建前失败仍留恢复清单并释放锁 |
| MacOS 完整生命周期 | 假 Go／临时回环服务经部署、信号退出、日志封口，再执行默认备份反部署；主流程未包装失败也封存并释放锁 |
| 路径与解释器 | 中文、空格及特殊字符工程，从工程外工作目录运行；`zsh` 分别封存运行资源和工具 |
| 外部数据库、活服务标记 | 外部数据库或文件写锁存在时阻止清源，不把本地文件复制称为数据库备份 |

## 三、<span id="evidence">输出与验证边界</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 独立运行输出逐项结果到终端；临时工程、假工具、备份和进程记录随用例释放，不留下正式业务数据。
- 统一入口将本脚本输出写入部署测试的 `证据/本轮/`，跨组摘要由统一入口登记。
- 测试以各平台真实脚本内嵌的 Shell 生命周期实现为主；临时函数库只在测试目录外生成，不是交付依赖。Windows 专用隔离测试及各系统原生双击验收分别登记。
- 隔离通过不能替代真实数据库恢复、目标系统服务管理、原生桌面双击或生产回退演练。
