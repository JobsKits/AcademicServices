## 🔥 <span id="前言">前言</span>

本目录验证[网页实际源码](../../../../代码/前端/PC端/Web/shop.js)的异步业务边界。测试以可控 DOM 和网络夹具执行当前源码，只在内存副本中暴露测试入口并关闭自动首屏请求，不修改产品源码，不连接真实服务、不读写浏览器持久化资料。

## 一、<span id="run">执行入口</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

在本目录使用 [**Node.js**](https://nodejs.org/) 20 或以上版本执行，不需要下载第三方依赖：

```shell
node ./并发.mjs
```

测试按本文件位置解析源码和本地资源，不依赖启动工作目录。断言失败以非零状态退出，并显示具体场景；所有测试定时器在场景结束时回收。

## 二、<span id="coverage">覆盖与当前结果</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

当前 14 项隔离场景已执行通过：

- 请求发出前冻结写入意图；并发重复提交不会产生第二个请求。
- 未知写入结果保留原幂等键；不同内容不能覆盖未核实意图。
- 新刷新优先于旧刷新；写入前或写入中启动的旧列表不能覆盖已确认的新订单版本。
- 退出和切换服务后丢弃迟到结果；旧请求不会解除新会话的写入门禁。
- 旧表单成功与失败均不关闭新表单，不覆盖新错误提示或按钮状态。
- 401 即使正文不是有效 JSON，也会撤销会话与授权缓存。
- 动作响应必须精确匹配订单并推进版本；新建响应必须对应原选商品。
- 个人资料通过 PUT 更新，保持当前认证用户编号。

这是业务与并发验证，不替代真实后端、屏幕布局、手机触控、轮播动效或目标浏览器验收；真实流程和原生端另见[原生验证](../原生/README.md)与[资产盘点](../../../../项目相关报告/桌面与Web资产盘点.md)。
