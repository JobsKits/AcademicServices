## 🔥 <span id="前言">前言</span>

`shop_test.dart` 验证用户端与管理端复用的商城源码。使用内存 HTTP 替身和隔离偏好设置，不连接真实支付，不修改运行中的业务数据。

`auth_repository_test.dart` 覆盖正式环境断网不生成用户权限、显式Demo后台admin/1234免登录、正式服务配置覆盖Demo编译标记、离线Demo邮箱注册／改名／用户名或邮箱登录／重置密码，以及正式邮件服务不可用时明确失败。

`auth_experience_test.dart` 通过真实商城组件与隔离 HTTP 替身验证账户体验，共15项。VM与Chrome分别检查共享界面及Web宽屏顶栏，覆盖游客首页、完整账户门、正式后台拦截、Demo自动进入、配置请求竞态、游客个人路由及鼠标轮播。

## 一、<span id="run">运行</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

在仓库根目录运行完整 Flutter 分组：

```shell
python3 './测试/运行测试.py/运行测试.py' --group flutter
```

只运行商城用例时，在 `../../../../代码/前端/移动端/Flutter/` 执行：

```shell
flutter test --no-pub ../../../../测试/前端/移动端/Flutter/shop_test.dart
flutter test --no-pub ../../../../测试/前端/移动端/Flutter/auth_experience_test.dart
dart analyze --format machine lib/Shop
```

需要已安装的 Flutter SDK 和锁定依赖，统一入口不自动安装。日志由统一入口写入前端测试证据目录；直接执行测试时输出到当前终端。

## 二、<span id="coverage">覆盖与边界</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 自有Web语义锚点无HTML平台视图覆盖；Tab将屏外链接滚入，Enter单次导航；手机订单筛选和分类顶层往返独立保留。
- URL公开参数白名单、详情直达及返回、订单状态与个人中心路由；登录后继续购买确认。
- 409拒绝保留三段需求、持续错误、原位重试；更新失败保留真实商品和订单；德文200%字号下需求／收银台／设置三弹窗。
- 九个子服务、三分类TabBar与横向PageView联动、详情分节、320／390／934／1440窗口。
- 个人中心四状态统计及跳筛选；动态当前演示凭据复制反馈及正式模式隐藏。
- 轮播连续向前循环、单图静态、自动播放／减少动效、可见与前后台、悬停／拖动／焦点暂停及键盘控制；初始本地三图默认、服务端成功空配置隐藏与商户编辑、图片URL及可选浏览器跳转。
- 订单需求／联系方式／交付要求，接单前编辑、商户接单后锁定，商品快照与金额不变。
- 双渠道模拟收银台；关闭不付款，主动确认后付款。
- 离线买方下单／支付、站方开工／交付、买方确认／评价及历史快照。
- 商品编辑字段过滤、版本、库存权限、真实空列表、离线恢复、错误口令不回退成功。
- 未知真实写保留原键与正文重试，避免重复订单。
- 十语言词条完整性、主题偏好恢复、暖色主副文字对比。
- 账户体验15项：游客浏览与唯一设置入口、移除常驻重新加载；登录／注册／忘记密码可达；注册密码不一致时留稿并保留错误；正式后台商品／订单／轮播深链均拦截；明确Demo自动以演示账号进入；正式设置隐藏连接地址及超时、Demo显示；登录后用户名／头像替换入口并自动刷新数据；首页轮播自动推进且分页点在图内右下。
- 游客设置不重复出现登录／切换账号按钮；点击“我的”或直达个人页先进入账户门，认证前不展示个人卡片，取消回首页；Web鼠标可拖动轮播，结束并移出悬停后恢复自动推进。
- Demo首次进入竞态：两次配置请求交错时，较早响应被更新请求淘汰，待最新响应明确Demo后仍会完成后台自动进入；身份建立前不展示业务工作区。

账户体验用例已在VM与Chrome各通过15项。当前Chrome测试编译器不能直接加载包外入口，Chrome验收使用包内临时测试副本并在结束后清理；正式测试文件保留在本目录。Widget替身结果不替代实际HTTP服务入口及邮件送达验收。

2026-11-05本轮最终四文件分组83项通过，其中商城49项；记录见[统一Flutter日志](../../报告与证据/本轮/2026.11.05%2023-46-07-719740/flutter-1.log)。两端`dart analyze --format=machine lib`零诊断。当前SDK的`flutter analyze`在LSP初始化时JSON截断退出，原始失败日志保留在[CLI分析记录](证据/商城/web-experience-flutter-analyze.log)，没有将该命令登记为通过。实际浏览器深链、历史、新标签与截图证据由商城总回归维护。

Widget 与替身测试通过不代表 Web 构建、iOS／Android 安装、微信／支付宝外部 App 唤起或真机验收。各端实际构建及设备证据由总回归登记。
