## 🔥 <span id="前言">前言</span>

测试微信原生商城的请求、状态、页面与恢复逻辑。使用[**Node.js**](https://nodejs.org/)内置 test，不写运行服务数据，不调用真实支付。

## 一、<span id="entry">运行与覆盖</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

```shell
node --test ./测试/前端/微信小程序/test_shop.cjs ./测试/前端/微信小程序/test_mini.cjs
```

在仓库根执行。商城及账户69项覆盖九商品／分类、真实空态与恢复、金额快照、下架缺货、双渠道模拟付款、关闭不付款、权限与确认／评价、四状态筛选、写锁、未知写原键对账／重试、错owner及迟到响应、十语言三主题、图片兜底及恢复。三Tab、个人中心四状态、轮播初始种子／后台恢复、成功空配置隐藏、图片私有文件转换、显式Demo／逐字段复制、需求编辑与接单锁定、外链限制与复制回退均有断言。原生轮播补充单图静态、多图循环、手势／切Tab／后台／离屏暂停、松手恢复、分页点选／迟到恢复取消与减少动效手动；轮播没有叠加JS定时器。HTTP与幂等20项补充会话及超时保护，总计89项通过。

体验路径断言实际加载页面与共享工具：未登录购买回到原详情且不自动下单／付款；登录失败保留表单；401清私有显示并可登录恢复；403／404移除不可访问详情并给出明确错误；请求失败保留带提示的已有真实内容；切账号清旧订单与草稿；普通Tab保留筛选、个人中心入口才改变筛选；同账号重新登录保留未提交需求，版本冲突／未知结果保留购买输入；商户展示卖方状态并拒绝买方操作。轮播失败保留最后成功配置，迟到响应不能覆盖成功空配置。

已以ShopClient经wx.request桥接真实隔离Go后端，验证合成邮箱注册、用户名登录、资料头像直接更新、密码重置和绑定邮箱登录；未接触运行中的真实业务数据。

账户回归还覆盖游客个人Tab先登录、失败／取消不进入个人页、成功后才切个人页、个人页深链／冷启动游客回首页开账户门、设置无游客登录入口及轮播同时支持自动和原生左右手滑。

账户回归覆盖邮箱注册与重置密码、用户名／邮箱登录、改名上传头像、验证码用途和重放、正式邮件不可用不伪成功、迟到认证不跨服务／会话、游客订单入口拦截、三种账户入口共存、Demo连接控制、设置唯一与常驻重载移除、图内分页与新增十语言词条。选择头像后换号会取消旧文件上传；仍未验证微信基础库真实图片选择、私有文件解码、SMTP真实收件或微信设备页面布局。

## 二、<span id="device">开发者工具与真机验收</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 开发者工具导入[小程序工程](../../../代码/前端/微信小程序/README.md)，使用实际 AppID 和合法域名；检查八页面与三Tab编译、三分类及九详情可达、空态重载、字体和长语言布局。当前未执行工具编译。
- iOS微信与Android微信分别真机预览；服务可达时从详情创建订单、关闭／重新打开收银台、支付宝／微信分别确认mock、由管理端交付、买方确认并评价。检查订单四状态筛选、下架／缺货阻止新购及历史快照。
- 真机分别切十语言、三主题与系统主题；断开后端查看本地品牌、初始演示或标记未刷新的真实内容，恢复后刷新采用服务端；未知真实写只核对／同键重试。核验原生返回／切Tab滚动位置、键盘输入恢复与轮播可见播放，后台全部下架后应隐藏运营位。真机不能使用电脑loopback地址。
- 工具／真机／体验版／提审／正式发布分别登记，当前均未验收；Node断言不能替代这些证据。mock不证明外部App支付SDK、签名或渠道回调已验收。
